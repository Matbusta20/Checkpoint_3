## Descrição do Projeto
O Hall da Farma é uma plataforma de gamificação e reconhecimento voltada para aumentar o engajamento dos colaboradores da Eurofarma em programas de inovação.

## Tecnologias
- WordPress + Plugins de Gamificação
- Angular (Front-end)
- Spring Boot + MySQL (Back-end)
